shogo v0.1.0

Documentation

shogo is a zero-dependency ES module that fans out to Jikan (MyAnimeList), Kitsu, AniList, animap.id, TMDB, AniSkip and Anime Skip, then merges everything into a single canonical shape. Source, docs and tests live in the same repository.

Install

npm install shogo-anime

# or just import the source in this repo — it is plain ESM:
# import { Shogo } from "./src/index.js"

Node 18+ works out of the box. Bun, Deno, browsers and embedded runtimes (QuickJS-ng, React Native) work too — see Runtime support. TypeScript needs only lib: ["ES2020"]; the package ships its own fetch types.

Quick start

import { Shogo } from "shogo-anime";

const shogo = new Shogo(); // Jikan, Kitsu, AniList, animap.id need no keys

const anime = await shogo.findById("mal:21");
anime.titles.romaji;   // "ONE PIECE"
anime.ids.shogo;       // "12000000210000002117"  (packed MAL + AniList + Kitsu id)
anime.sources;         // ["jikan", "anilist", "kitsu", "animap"] — who contributed
anime.meta;            // { durationMs, cacheHits, coalesced, ... }

await shogo.findById(2105);          // bare ids are shogo ids
await shogo.findById("one-piece");   // bare text is a slug
await shogo.findById("tt0388629");   // IMDb ids welcome

Only TMDB (images/stills, IMDb+TVDB bridge) and Anime Skip (optional second skip source) need keys — skip times already work keyless via AniSkip.

The one shape

Every method returns the same normalized model and the same envelope — no provider JSON parsing on your side: 

const anime = await shogo.findById("mal:21");

anime.ids;          // { mal, anilist, kitsu, anidb, ann, tvdb, tmdb, imdb, shogo, ... }
anime.titles;       // { romaji, english, native, synonyms, localized }
anime.slug;         // "one-piece"  (+ anime.slugs for native provider slugs)
anime.episodes;     // 1184        durationSec, season { season, year }, aired { from, to }
anime.ratings;      // { mal: { score, votes, ... }, anilist: {...}, kitsu: {...} }
anime.score;        // 8.55 — shogo score: the average of every provider score, normalized 0–10
anime.images;       // { posters, banners, logos, thumbnails, stills } (each with .source)
anime.links;        // { official, streaming: [{ service, url, dub, subs }], external }
anime.relations;    // [{ type: "SEQUEL", ids, title, format }]

anime.errors;       // [{ provider, code, message }] — partial failures, never thrown
anime.skipped;      // [{ provider, reason: "no-key" | "not-found" | ... }]
anime.meta;         // { durationMs, cacheHits, coalesced, providersQueried }
anime.fieldSources; // { synopsis: "anilist", "titles.romaji": "jikan", ... }

Array-returning methods (episodes, seasons, characters, staff, franchise) carry the envelope on the array itself: eps.errors, eps.sources, eps.meta.

IDs

Packed shogo IDs (no database)

A shogo ID packs the MAL, AniList and Kitsu ids into one checksummed number. Decoding is pure math — zero network, zero cache. 

shogo.ids.toShogo({ mal: 21 });                        // "2105"
shogo.ids.toShogo({ mal: 21, anilist: 21, kitsu: 12 }); // "12000000210000002117"
shogo.ids.fromShogo("2105");                           // { mal: 21 }
shogo.ids.fromShogo("2106");                           // null — checksum rejects typos
shogo.ids.equivalent("2105", "12000000210000002117");  // true (id-set intersection)
shogo.ids.merge("2105", "12000000210000002117");       // { ids, conflicts: [] }

Store populated ids as strings — they exceed Number.MAX_SAFE_INTEGER. Missing slots are zeros; leading empty slots are trimmed, so partial ids stay short.

Slugs

shogo.ids.slugify("Bocchi the Rock!"); // "bocchi-the-rock"

// resolution order: native Kitsu slug (1 exact request) -> loaded catalog index
//                   -> identify() at a higher threshold
match.best.ids;        // { kitsu: 12, ... }
match.best.confidence; // 1

Options

const shogo = new Shogo({
  keys: { tmdb: "...", "anime-skip": "..." }, // only used when needed
  providers: ["jikan", "kitsu", "anilist", "animap"], // hard allow-list (also for search)
  defaultSource: "kitsu",     // kitsu | jikan | anilist — leads the merge + episode defaults
  baseUrls: { jikan: "https://my-jikan.internal/v4" },  // self-hosted Jikan
  rateLimits: { anilist: { perMin: 25 } },
  cache: "memory" | false | { get(k), set(k, v, ttlMs) },
  timeoutMs: 10000,
  proxy: "/api/proxy",        // backend mode: route every provider call through a server endpoint
  concurrency: 4,
  hooks: { onRequest, onResponse, onError },      // see Resilience
  clock: { now, sleep },                          // for tests / tiny runtimes
  fetch: myFetch,                                 // bring-your-own fetch
});

// per call:
await shogo.findById("mal:21", {
  include: ["titles", "ids.shogo"],   // dotted selectors, prune the provider plan
  exclude: ["relations"],
  dryRun: true,                        // return the call plan, fetch nothing
  cache: "bypass",
});

Keyed providers throw an actionable MissingApiKeyError when a method cannot be answered without them — and are skipped (with skipped: { reason: "no-key" }) when they are optional.

Mapping caveat

There is no keyless MAL→TMDB bridge (Jikan/Kitsu/AniList don't carry TMDB ids and animap deliberately doesn't either). TMDB joins a lookup when you pass a tmdb:/tt…/tvdb: id — or when you find the entry through search()/ identify().

Episodes & skip times

const seasons = await shogo.seasons("mal:21");
const eps = await shogo.episodes("mal:21");                                   // kitsu (default source)
const all = await shogo.episodes("mal:21", { providers: ["jikan", "kitsu", "tmdb"] });
// every episode carries `refs` (each provider's own numbering) and the list
// carries `consolidated` { providers, total, matched, unmatched }

const ctx = await shogo.episode("mal:21", { season: 1, number: 1, providers: ["jikan", "kitsu"] });
// ctx.anime    -> the full merged Anime
// ctx.season   -> which Season it belongs to
// ctx.episode  -> number/title/air date/thumbnails
// ctx.skip     -> { op, ed, recap } from AniSkip by default (keyless); null when nothing is stored
// ctx.images   -> stills/screenshots

// Apply the branding offset for the service you actually watch on:
await shogo.skipTimes("mal:21", { number: 1, serviceUrl: "https://www.crunchyroll.com/..." });

Consolidation: flat lists and season 1 align on the episode number; deeper TMDB seasons align via (season, number) or absoluteNumber; episodes that match nothing are surfaced in consolidated.unmatched — never dropped. Tagged TMDB with no { season } fetches every numbered season so a whole show can align. Provider tags select episode sources only — the anime record still merges the full metadata set.

Skip times default to AniSkip (keyless; real ranges) with Anime Skip as an optional fallback; tagging anime-skip without a key throws MissingApiKeyError (it asks for it). A rejected client id throws InvalidApiKeyError (INVALID_KEY) naming the fix, and the app validates the id inline in settings. Missing pieces are reported as no-key / no-anilist-id / no-mal-id / not-found. Pass { episodeLength } (seconds) to pick the matching stored variant — AniSkip keeps one per release length, and episode() passes the episode's own duration automatically.

Resilience & hooks

  • Parallel by default: mapping sources and provider fan-out run concurrently — a lookup costs roughly the slowest provider, not the sum.
  • Rate limits per provider with sane defaults (Jikan 3/s + 60/min, AniList 30/min, …), self-tuned from X-RateLimit-* headers.
  • Timeouts are never retried, and a provider that fails goes on a 60s cooldown (failure cache — cache: "bypass" re-probes; a success clears it). A per-provider circuit breaker backs this up.
  • Cache: in-memory by default, ETag revalidation, negative caching, request coalescing; cache: false or any custom store.
  • Observability: hooks, result.meta, dryRun plans, stats().
const shogo = new Shogo({
  hooks: {
    onRequest:  (e) => log.debug(e.provider, e.url),          // urls are redacted
    onResponse: (e) => metrics.observe(e.provider, e.durationMs),
    onError:    (e) => log.error(e.provider, e.error, e.willRetry),
  },
});

await shogo.findById("mal:21", { dryRun: true });
// { plan: [{ provider: "jikan", native: { kind: "mal", id: 21 } }, ...] }

shogo.stats(); // http counters, cache hits, limiter waits, breaker states

Runtime support

All network traffic goes through one replaceable function (new Shogo({ fetch })); there are no node: imports and no assumptions about URL, timers or AbortController. 

// QuickJS-ng / React Native / anywhere without a global fetch:
import { Shogo } from "shogo-anime";
import { fetch } from "your-host-fetch-binding";

const shogo = new Shogo({
  fetch,
  clock: { now: () => Date.now(), sleep: (ms) => hostSleep(ms) }, // only if timers are missing
});

Subpaths: shogo-anime/ids (pure, ~2 KB), shogo-anime/core, shogo-anime/testing (mock fetch for your own tests). Browser CORS is verified open (*) for Kitsu, AniList, animap.id, TMDB and Anime Skip; Jikan is browser-friendly too.

Backend mode: new Shogo({ proxy: "/api/proxy" }) routes every provider call through your server (shogo.transport === "backend"), so the browser only talks to your backend. The docs server implements a hardened proxy (host allow-list, body/header forwarding, server-side TMDB_API_KEY / ANIME_SKIP_CLIENT_ID injection); the app and playground have a frontend/backend switch.
