providers & keys

fetch mode

backend routes every provider call through /api/proxy on this server (run node docs/serve.mjs; only works there). Use it when your browser's network can't reach a provider, or set TMDB_API_KEY / ANIME_SKIP_CLIENT_ID env vars on the server to keep keys off the client.

default source

Leads the metadata merge and picks the default episode list provider (AniList maps to Kitsu for episodes). Pick kitsu when api.jikan.moe is unreachable.

skip times

aniskip is keyless and answers first; anime-skip joins as a second source once a client id is set.

Stored in localStorage only. Keyless providers work immediately; a TMDB key unlocks stills/backdrops, and an Anime Skip client id adds a second skip-time source on top of AniSkip (which needs no key).

live: kitsu · anilist · animap.id · aniskip — no keys needed
